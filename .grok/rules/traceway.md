# Traceway

The Laravel planner is in `apps/app` and the Astro content site is in `apps/web`. Read `AGENTS.md` first. Domain code does not import Saloon, Eloquent, or HTTP. Outbound HTTP is a Saloon connector. Route geometry comes from the routing engine. Device names are 1 to 15 characters. Biome formats JavaScript, Pint formats PHP, and PHPStan runs at level max. The marker color is chartreuse. Do not use Strava orange, their wordmark, or their product words. A branch that changes something riders use adds its rider notes in `apps/app/resources/releases/unreleased/<branch>.md`. A release is cut only by the Release workflow: follow `.agents/skills/release/SKILL.md`. Open a pull request by following `.agents/skills/pr/SKILL.md`.
