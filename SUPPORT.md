# Getting help

- **A question about using or running Traceway**: ask in [GitHub Discussions](https://github.com/NxT-Solutions/Traceway/discussions), in the Q&A category.
- **An idea**: start a discussion in the Ideas category, or open a [feature request](https://github.com/NxT-Solutions/Traceway/issues/new/choose) if it is concrete.
- **Something is broken**: open a [bug report](https://github.com/NxT-Solutions/Traceway/issues/new/choose).
- **A device does not load or follow an exported course**: open a device report.
- **A security problem**: report it privately. See [SECURITY.md](SECURITY.md).

Traceway is maintained in spare time. There is no paid support, and answers can take a few days.

Traceway is free, and it always will be. If you enjoy it, you can [chip in for the hosting](https://traceway.online/support).
