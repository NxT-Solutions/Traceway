section: Fixes
---
- **Long loops stop riding back down the same road.** A loop only rides a road both ways on the street it starts from, so you can get home. Before, a long loop could ride several kilometres back down a road it had already used.
- **Says when a bent loop rides back on itself.** When you bend a loop and it now rides back down a road for a while, Traceway tells you, on long loops too.
