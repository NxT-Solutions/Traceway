section: Fixes
---
- **Multisport legs stop riding back down the same road.** A bike or run leg only rides a road both ways on the street it starts from, however long the leg, and never back down a road an earlier leg used.
- **Fewer roads ridden twice when there is no clean way.** When every loop Traceway finds rides back down a road for a while, it now picks the one with the least of it.
