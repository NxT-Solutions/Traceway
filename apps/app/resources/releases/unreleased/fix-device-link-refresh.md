section: Fixes
---
- **A linked device shows up at once.** After you type the code, the device is in the list as waiting, and it changes to linked by itself when the device answers. You no longer need to reload the page.
- **The form clears after linking.** The code empties and the name goes back to Garmin, ready for the next device.
- **Easier to type the code.** The code has six boxes, like on the device, and letters turn into capitals as you type.
- **Where to find Traceway on your Garmin.** Settings, then Devices, says where the app is on an Edge bike computer and on a Forerunner or fēnix watch.
